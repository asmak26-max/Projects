# 📂 Python File Organizer

A Python automation mini-project for simplifying **file and folder organization**.

## 💡 Overview

The project explores how Python can automate repetitive file-management tasks and make directory organization easier.

## ✨ Highlights

- Automated file organization
- Supports directory-based processing
- Optional subfolder handling
- Automatic folder management
- Undo capability for recent changes

## 🛠️ Technology

- **Python**
- `os`
- `shutil`
- `json`

## ▶️ Run

```bash
python pwp_file_org.py
```

Follow the prompts displayed in the terminal.

## 🎯 Purpose

This project was created as a **Python automation and learning project**, focusing on file-system operations, modular programming, and automation.
