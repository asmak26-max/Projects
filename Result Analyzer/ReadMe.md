# Result-Analyzer_Demo

📊 Result Analyzer

Result Analyzer is an automation-based application developed to simplify student result collection and analysis from the MSBTE result portal.

🚀 What It Does

The system allows users to provide student enrollment numbers through an Excel file and automatically processes the corresponding result data into a structured Excel report.

✨ Key Features
Automated result data collection
Excel-based input
Structured result processing
Excel report generation
Reduced manual effort and errors
🛠️ Technology Stack

Java, Spring Boot, Selenium, JSP, JavaScript, Apache POI
