# 🛒 Mini Shopping Mall — C Mini Project

A console-based C application developed to practice core C programming concepts through a small, menu-driven shopping and billing system.

## 🎯 Project Objective

To build a small real-world style application that demonstrates how fundamental C concepts can be combined to create a functional billing workflow.

### Core Flow

```text
User Input
    ↓
Menu Selection
    ↓
Category / Item Selection
    ↓
Quantity Input
    ↓
Cost Calculation
    ↓
Final Bill
```

---

## 🧠 Concepts Demonstrated

- `switch-case` for menu-based navigation
- Nested decision-making for sub-menus
- `for` and `do-while` loops
- Arrays for managing multiple values
- Structures for grouping related data
- Functions for modular programming
- Basic input/output using `scanf()` and `printf()`
- Arithmetic operations for billing calculations
- Basic input validation and control flow

---

## 🏗️ High-Level Design

The application is divided into independent functional areas:

```text
Mini Shopping Mall
│
├── Shopping Module
│   ├── Grocery
│   └── Home Appliances
│
└── Food Court Module
    └── Billing
```

The implementation uses functions and data structures to keep different responsibilities organized.
