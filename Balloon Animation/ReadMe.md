# 🎈 Balloon Animation — C Graphics Mini Project

A simple graphics-based C mini project that creates an animated balloon scene using the classic BGI graphics environment.

The project was developed to practice **C programming fundamentals, graphics programming, animation logic, and coordinate-based movement**.

🎯 Project Objective

To create a simple real-time graphical animation where multiple balloons continuously move upward across the screen.

### Core Flow

Initialize Graphics  
↓  
Create Balloon Positions  
↓  
Animate Balloons  
↓  
Update Coordinates  
↓  
Redraw Frame  
↓  
Repeat Until Exit

---

🧠 Concepts Demonstrated

- C programming fundamentals
- Graphics programming using `graphics.h`
- Coordinate-based object movement
- Arrays for managing multiple objects
- `for` loops for repeated processing
- Random number generation
- Real-time animation using delays
- Screen clearing and redrawing
- Keyboard-based program termination
- Basic graphical primitives such as circles
- Boundary checking and object repositioning
